Mobile App Tester

Singapore

Apply Now →

Role Overview

Help Vinova ship apps that work flawlessly. You will test mobile apps on real iOS and Android devices, find issues early and work with developers to resolve them before launch.

Key Responsibilities

  • Plan and run manual test cases for iOS and Android apps
  • Test functionality, usability, compatibility and performance on real devices
  • Log clear, reproducible bug reports and verify fixes
  • Run regression tests before each release
  • Give feedback on user flows to designers and developers

Requirements

  • Experience testing mobile apps, or relevant coursework or internships
  • Good understanding of the software testing lifecycle
  • Strong attention to detail and clear written English
  • Comfortable using both iOS and Android devices
  • Able to work well with developers and project managers

Bonus Points

  • Experience with bug tracking tools such as Jira
  • Familiarity with TestFlight or Firebase App Distribution
  • Basic knowledge of test automation (e.g. Appium)
  • Experience testing APIs with tools such as Postman

Why You Will Love Working Here

  • Work on real projects for clients across banking, healthcare, commerce and more
  • A friendly, close-knit team that values ethics and teamwork
  • Room to learn and grow alongside experienced colleagues
  • A modern, agile way of working
  • Compensation and benefits are discussed during the interview
